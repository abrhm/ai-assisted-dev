# ai-assisted-dev

A polling api where users can create polls with multiple options, vote on open polls, close polls to stop further voting, and track which polls they haven't voted on yet.

## User Stories

- [ ] As a user, I want to create a new poll with a title and options so that others can vote on it.
- [ ] As a user, I want to vote on an open poll by selecting one of its options.
- [ ] As a user, I want to close a poll so that no more votes can be submitted.
- [ ] As a user, I want to see which polls I have not voted on yet.

## Commands

- `npm start`: Runs the app
